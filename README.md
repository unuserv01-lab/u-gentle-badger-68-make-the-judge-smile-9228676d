Entrants write a single line of at most 200 characters about a small good thing that happened today, something that would make a reader smile. A judge model compares entries two at a time on the published brief: on subject first, then warmth, then surprise, then one concrete detail, then fresh wording. The warmest and most surprising line wins.

## Run it

```sh
node main.ts
```
